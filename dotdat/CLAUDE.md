# CLAUDE.md

Read [AGENTS.md](AGENTS.md). It is the single source of agent instructions for
this repository: commands, repo map, invariants and conventions.

DOTDAT is a functional copy of Clarion Viewer's read-only browser, built by
black-box reverse engineering. The feature comparison, evidence and deliberate
differences are in [docs/CLAVIEW.md](docs/CLAVIEW.md).

To run the app: `dotdat gui` from an activated venv, or double-click
`build\nuitka\dotdat.dist\dotdat.exe`. Full instructions:
[README - Run](README.md#run-dotdat).
